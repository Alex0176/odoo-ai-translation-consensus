AI Translation Consensus

Several AIs translate and proofread. They check each other.

Language models and translation services (with or without API key) work on the same text, rate each other's results anonymously and agree on the wording that is both accurate and natural. Without agreement a human decides. By default a human approves every proposal.

Getting started

  1. Open AI Translation ▸ Providers, enter keys where needed, press Test connection, activate two or more.
  2. Open AI Translation ▸ Start here. The wizard explains the module and creates a rule: records, fields, languages, providers, hints.
  3. On the rule press Scan now (lists the texts, free), then Process one batch until the queue is empty.
  4. Review the Proposals: apply, choose another wording, write your own, or reject.

Texts leave your server when a hosted provider is used; mark a rule Confidential to restrict it to providers on your own infrastructure.
